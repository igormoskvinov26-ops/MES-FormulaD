# Brand logo — DO NOT GENERATE

Place the **original, designer-provided** РублЪ logo here as:

```
assets/logo/rubl_logo.svg
```

## Critical rule (spec §7)

The РублЪ brand logo must **NEVER** be generated, redrawn, recreated, traced,
approximated, AI-generated, or altered in any way (letters, the razor inside the
mark, proportions, or a "similar" version).

Only the following are allowed:

- proportional scaling,
- positioning,
- technical export.

This directory intentionally does **not** contain a logo file. The Story
renderer detects the missing asset and renders a neutral, clearly-labeled
placeholder box (never an imitation of the brand mark). Drop the real
`rubl_logo.svg` here to enable the real logo.
