# UI-бриф: «FormulaD MES 2.0» — первый экран

## Стиль

Современный компактный промышленный интерфейс для производственного цеха, **не игрушечный**. Светлый фон, контрастные заголовки и состояния, минимальные декорации. Акцент — приглушённый фиолетово-синий с нейтральными серыми; предупреждения — янтарные, критические — красные, успешные — зелёные. Хорошая читаемость на стационарных ПК, крупное поле ввода для сканера. Иконки только при функциональной необходимости.

```text
Панель изделия (по клику / Enter)

```

## UX

- `Ctrl/Cmd+K` фокусирует поиск VIN (по возможности), Enter при полном VIN открывает карточку, сканер в режиме клавиатуры должен работать без отдельных драйверов.
- Не терять фокус поля при обновлении таблицы. Учитывать быстрый поток символов и клавишу Enter после скана.
- Отдельно показать бейдж DEMO, чтобы оператор не принял демонстрационные записи за настоящие.
- Грамотная русская терминология, цвета статусов не подменяют текст.
- Пустые даты — «—», а не «01.01.1970»; при неясном часовом поясе не преобразовывать SQL локальное время в UTC.
- Таблица сортируется по VIN (без утверждения, что это порядок физической линии).
- Предусмотреть скелетон/«Загрузка», «Ничего не найдено», «Нет доступа», «Нет связи с сервером».
- Доступность: клавиатура, фокус, контраст, aria labels, масштабирование 125%.

## Не включаем

Визуальная линия с 11 станциями, движение квадроцикла, ОТК, криппл, экспорт Excel, печать, изменение статусов — будущие итерации. Не допускать фиктивных «работающих» кнопок.
