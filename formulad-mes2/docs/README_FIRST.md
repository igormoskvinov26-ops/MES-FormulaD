# FormulaD MES 2.0 — передача Codex / MVP 0.1

**Дата:** 26 октября 2026 года. **Статус:** проектирование и локальная разработка. **PROD — не изменять.**

## С чего начать

1. Распаковать эту папку на компьютере разработчика (Mac). Не распаковывать на ВМ `SQLACCESS`.
2. Открыть папку в Codex (новый проект/repository). Рекомендуемое имя локальной папки: `formulad-mes2`.
3. Отправить Codex одну команду: **«Прочитай `CODEX_START.md`, затем реализуй MVP 0.1 строго по документации. Начни с безопасного локального демо и тестов. Не обращайся к SQLACCESS или FormulaD.»**
4. Codex должен самостоятельно создать исходники (`apps/web`, `src/FormulaD.Mes.Api`, `tests`), запустить доступные тесты, описать команды запуска, показать результат и оставить список нерешённых вопросов. Когда какой-либо инструмент отсутствует, он должен явно сообщить и не заявлять, что тесты пройдены.
5. На первом этапе показываем UI на **синтетических данных**. Реальное соединение с SQL допускается позднее, исключительно с тестовой БД и SQL-пользователем **только на чтение**.

## Состав

- `CODEX_START.md` — основное задание Codex, обязательное к прочтению.
- `docs/ARCHITECTURE.md` — схема компонентов и среды.
- `docs/AS_IS_FACTS.md` — подтверждённые реальные факты из SQL и Access, без секретов.
- `docs/DB_CONTRACT.md` — фактические поля `dbo.tblProductionPlan` и важные ограничения.
- `docs/API_CONTRACT.md` — HTTP-эндпоинты, ответы и ошибки.
- `docs/UI_BRIEF.md` — дизайн и сценарии.
- `docs/SECURITY_AND_DEPLOYMENT.md` — политика запретов, DEV/TEST/PROD.
- `docs/ACCEPTANCE.md` — проверяемые условия приёмки и тест-кейсы.
- `docs/BACKLOG.md` — маленькие задачи по порядку.
- `sql/readonly_templates.sql` — **только шаблоны SELECT**, не запускать против PROD в автоматическом режиме.
- `fixtures/production-plan.demo.json` — вымышленные записи для экрана.
- `docs/OPEN_QUESTIONS.md` — вопросы перед дальнейшей миграцией.

## Жёсткое ограничение

В `FormulaD` нет подтверждённого резервного копирования: `msdb.dbo.backupset` пуст, задания SQL Agent бэкапа не обнаружены, восстановление не проверено. Запрещено использовать PROD для разработки, тестового импорта, создания логинов/схем и миграций без отдельного решения и согласования.

Не пересылать Codex оригинальные файлы Access или выгрузку с VBA/секретами, пока не проведена корпоративная проверка и обезличивание. Этот пакет специально подготовлен без исходных паролей.
