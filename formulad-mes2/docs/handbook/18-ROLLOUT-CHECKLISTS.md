- [ ] ОС и ресурсы соответствуют ожиданиям (`<определить: целевая ВМ>`; в AS-IS — Windows Server 2019, SQL Server 2019 Enterprise).

Колонка «Экран» — пункт бокового меню приложения. Проверять против изолированной TEST-БД (G1) и повторять в пилоте. Отмечайте результат: ☐ прошло / ☐ не прошло (+ ссылка на дефект).

**Разбор инцидента (форма):** хронология; что было известно в момент решения; что сработало/не сработало; корневая причина; корректирующие и предупреждающие меры; нужно ли обновить документы/чек-листы.

## 9. Чек-лист оператора на смену во время пилота

Для операторов и бригадира пилотного участка. Печатается как памятка у поста (T-123). Контакты: дежурный `<определить>`, бригадир `<определить>`.

### Начало смены

- [ ] Вошёл **под своей** учётной записью (не чужой, не общей); при смене оператора на посту — выполнил смену пользователя.
- [ ] Открылся нужный экран (Старт / Завершение / FOK / Станции / Rework / Несоответствия / Входной контроль).
- [ ] Сканер работает: пробный скан даёт текст в поле ввода; курсор в поле скана.
- [ ] Принтер на месте, бумага есть; JobCard печатается и читается сканером.
- [ ] Знаю, где бумажный/обходной сценарий и кому звонить.

### В течение смены

- [ ] Работаю **только с изделиями своего участка** (правило «одно изделие — одна система записи»). Незнакомое/чужое изделие — не трогаю, зову бригадира.
- [ ] Первый скан — смотрю карточку и причину (если блокировано); второй скан/кнопка — подтверждаю. Подтверждаю **то же** изделие, которое показано.
- [ ] Если система показала ошибку — **читаю причину**, не повторяю подряд; статус не меняется «молча».
- [ ] Блокировка FOK из-за неустановленной детали: открываю Несоответствия или отправляю в Rework — не пытаюсь обойти.
- [ ] Не закрываю NCP «чтобы прошло»: «деталь установлена» и «закрыть заявку» — разные действия.
- [ ] Нашёл расхождение/странность — записываю VIN и что видел, сообщаю бригадиру (журнал инцидентов).
- [ ] Не нажимаю дважды «подтвердить»/«публиковать» — жду ответа; повтор проверяется системой, но лучше не рисковать.
- [ ] Не выхожу из системы/не закрываю вкладку посреди операции.

### Что делать, если

| Ситуация | Действие |
|---|---|
| Не открывается / «нет связи с сервером» | Подождать минуту, обновить страницу; не помогло — бригадир → дежурный; работа по обходному сценарию |
| Скан не читается | Ввести VIN вручную; проверить раскладку/язык; повторить |
| «VIN не найден» | Проверить символы; сообщить бригадиру (возможно, изделие не на моём участке) |
| «Статус … ожидался …» | Изделие не в том состоянии; не пытаться «обойти»; сообщить бригадиру |
| Операция не прошла, неясно, выполнена ли | **Не повторять сразу**: открыть карточку изделия, проверить статус; сообщить бригадиру |
| Кажется, что данные неверные | Записать VIN и что видите; сообщить; фото экрана приветствуется |

### Конец смены

- [ ] Все начатые операции доведены или передаются сменщику с пометкой.
- [ ] Вышел из системы.
- [ ] Передал бригадиру замечания и записи для журнала инцидентов.
