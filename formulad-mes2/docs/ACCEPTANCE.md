# Проверяемые критерии приёмки MVP 0.1

## Функциональные

- AC01: чистая установка по README на Mac локально запускает API и UI без SQL Server.
- AC02: в шапке есть заметный DEMO-маркер, синтетические записи и невозможность изменить их.
- AC03: таблица содержит VIN, модель, цвет, статус, дату начала; поиск/фильтры/пагинация работают.
- AC04: при вводе существующего полного DEMO VIN и Enter открывается read-only карточка; отсутствующий VIN даёт 404/«Не найдено».
- AC05: пустые даты показываются «—», оригинальный status не теряется, неизвестный status не ломает UI.
- AC06: поиск работает как с клавиатурой, так и с эмуляцией «быстрый ввод + Enter».
- AC07: при отсутствии авторизации business API возвращает 401 (включая попытку прямого GET без UI).
- AC08: режим дев-аутентификации требует отдельной настройки секрета; отключён вне Development; без секрета запуск блокирует защищённый business API.
- AC09: `GET /api/v1/health/live` отвечает, не раскрывая названия хоста SQL или строки подключения.
- AC10: нет POST/PUT/PATCH/DELETE для продукции; frontend не содержит активных команд записи.
- AC11: неверный page/pageSize и слишком длинный VIN дают 400; pageSize>100 не принимается.
- AC12: тестовая инфраструктура не имеет зависимости от настоящих Access или SQL данных.

## Качество

- QA01: `dotnet build`, `dotnet test`, `npm run build` проходят либо в отчёте ясно указано, почему проверка отсутствовала.
- QA02: frontend тесты на поиск/пустую выдачу/ошибку сети/Enter и backend тесты на авторизацию, фильтр, пагинацию, 404 и 400.
- QA03: в коде отсутствуют `SQLACCESS`, connection secrets, `sa1`, пароль из Access, системный PIN.
- QA04: `docs/IMPLEMENTATION_REPORT.md` содержит перечень реализованного и известные недоработки, шаги запуска/остановки, фактические команды тестов и их результат.
- QA05: `git status` показывает только ожидаемые исходники, без скрытых .env/credentials.

## Граница приёмки

MVP 0.1 **не проходит промышленную приёмку** и не считается работающей MES для цеха. Это отлаженная программная основа для дальнейшего подключения к TEST SQL и последующего поэтапного внедрения.
